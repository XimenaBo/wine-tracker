Setup guide

  1. Go to console.cloud.google.com
  2. Create a project (e.g. "Wine Tracker")
  3. Enable the Google Drive API and Google Picker API
  4. Create an API Key — restrict to Drive + Picker APIs
  5. Create an OAuth 2.0 Client ID — type: Web application
  6. Add your GitHub Pages URL to Authorised JavaScript origins
    e.g. https://yourusername.github.io
  7. Paste the Client ID and API Key above and click Connect
